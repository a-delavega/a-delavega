### 🚀 What I'm currently building

**[minimax-parallel-benchmark](https://github.com/a-delavega/minimax-parallel-benchmark)** — An HPC research testbed in **C++20** evaluating parallel game-tree search (Lazy SMP) against sequential Alpha-Beta pruning on Connect 4:
- 64-bit Bitboard engine with `O(1)` branchless win detection and 32-byte cache-line alignment
- Pure Minimax vs Alpha-Beta with tactical move ordering, reducing effective branching factor to `b* < 3.0`
- CPU microbenchmarks measuring latency at **~3–5 ns** per primitive operation
- Multi-platform CI/CD pipeline (Ubuntu GCC/Clang + Windows MSVC) via GitHub Actions
- Comprehensive technical documentation in [`docs/`](https://github.com/a-delavega/minimax-parallel-benchmark/tree/main/docs)
